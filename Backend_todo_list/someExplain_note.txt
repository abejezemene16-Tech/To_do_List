Example Where subfolderID =? and 
        Where subfolderID =[subfolderId]  


        The database driver substitutes the parameter safely.
        This is called a parameterized query.
        It is preferable to building SQL manually with string concatenation.

INSERT INTO folders (name, color)
VALUES (?, ?)

allows the database library to safely parameterize the values.
This helps protect against SQL injection and handles escaping correctly.

"INSERT INTO folders (name, color)
 VALUES ('" + name + "', '" + color + "')"
